# 错题本 UI 静态 Demo

5 款完全本地的设计方案，无外部字体、图片、CDN 或后端依赖，不会修改正式系统。

## 打开

直接用浏览器打开 `index.html`，再点击卡片进入各方案。macOS 也可以在项目根目录执行：

```bash
open demos/ui/index.html
```

每个方案顶部数字 `1–5` 可以快速切换。页面使用演示数据，按钮只显示提示；科目筛选和错题搜索可以实际操作。

## 方案

1. **清爽学习蓝**：现代、清晰、通用，效率与舒适度均衡。
2. **暖纸手账**：纸张、胶带、衬线标题，温暖的学生笔记本气质。
3. **深色专注**：石墨色与薄荷绿，适合夜间与高密度使用。
4. **极简编辑**：黑白细线与朱红强调，杂志式排版。
5. **活力玻璃**：渐变、磨砂与圆润卡片，轻松年轻。

## 适配

- 手机优先：底部常用导航、双列统计、单栏上传与复习卡片。
- 平板：四列统计、上传与复习双栏。
- 桌面：完整顶部导航与宽屏工作区。
- 已按 360px、390px、834px 视口检查横向溢出。

`screenshots/` 保存了手机和平板预览图。
